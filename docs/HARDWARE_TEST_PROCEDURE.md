# Yamaha Disklavier 実機接続・手動安全性確認手順書

> [!WARNING]
> 本手順書は **実機 Yamaha Disklavier（Mark IV / E3 / ENSPIRE Pro）** を接続した状態での手動検証用プロトコルです。  
> 自動テスト（`./scripts/run_ci_local.sh`）では物理ソレノイドを連続駆動しない設計になっています。実機接続時は必ずピアノの前に人が待機した状態で順番に確認してください。

---

## 1. 事前準備・安全チェック

1. **ハードウェア結線確認**
   - Yamaha Disklavier MIDI IN / OUT ポート（または USB MIDI）を Mac へ接続する。
   - オーディオインターフェース（例: Steinberg UR22mkII）を接続し、チェロ収音・残響測定用コンデンサマイク（AKG C519ML）の +48V ファンタム電源およびゲインが過大でないこと（クリッピングしない -12dBFS 目安）を確認する。
2. **ループバック限定起動（初回接続推奨）**
   ```bash
   ./run_studio.sh
   ```
   - デフォルトは `127.0.0.1:8765` にバインドされ、同一マシン以外のネットワークからはアクセスできない状態で起動します。
   - ブラウザで開いた上部ヘッダーに MIDI ポート名（`Virtual Twin Mode` ではなく接続中の Disklavier ポート名）とオーディオ入力デバイスが表示されることを確認します。
3. **実機モデルの安全プロファイル選択**
   - UI の **「🛡️ 安全監視＆実機プロファイル」** タブ（`#vtab-safety`）または `POST /api/safety/profile` で、接続中のピアノ世代に合うプロファイルを設定します。

| プロファイル ID (`profile_id`) | 推奨対象機種 | 同時打鍵上限 (Soft/Hard) | 最大同時保持音数 | 秒間打鍵上限 | 最小音価 | 最長単鍵保持 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| `envious_mark_iv` *(既定)* | Disklavier Mark IV / E3 標準機 | 12 / 16 音 | 20 音 | 28 音/秒 | 35 ms | 8.0 秒 |
| `dkv_e3_conservative` | ヴィンテージ機・省電力・長時間連続演奏 | 10 / 12 音 | 16 音 | 22 音/秒 | 40 ms | 6.0 秒 |
| `dcx_enspire_pro` | DCX / ENSPIRE Pro 等・高速高精度アクション | 14 / 16 音 | 22 音 | 30 音/秒 | 30 ms | 10.0 秒 |

## 2. 緊急停止（PANIC）とソレノイド保護の単体動作確認

1. **Emergency Panic 疎通テスト（無音状態 → 小音量テスト）**
   - UI 右上の **「🛑 全音緊急停止 (PANIC)」** ボタンを押下（または `POST /api/panic`）。
   - `DisklavierSafetyGuard.emergency_panic()` が以下を実行することをサーバーログおよび実機挙動で確認します：
     1. スケジューラ優先度キュー（`_event_heap`）および解放予定テーブル（`planned_key_off_time`）を即座に破棄し、Condition 待機スレッドへ通知（`_cv.notify_all()`）。
     2. CC#64 = `0`（サステインペダル即時解放）を送信。
     3. 全 88 鍵（MIDI ノート `21..108`）に対し `note_off`（リリースベロシティ `64`）を送信。
     4. CC#123 = `0`（All Notes Off）を送信し、アクティブボイス管理状態をクリア。
2. **弱音単音発音チェック（A4 / C4）**
   - Virtual Keyboard（88鍵UI）で `C4`（中央ド）を軽くクリックし、ハンマーが正常に立ち上がり、`8.0 秒` 以内（通常音価で即離鍵）に安全に消音されることを確認する。

## 3. VDL（機械発音遅延）キャリブレーションとペダル残響実験（手動実行）

実機の機械的発音遅延（Velocity-Dependent Latency）は弱打（`pp`）で 100ms 超、強打（`ff`）で 30ms 前後まで変化します。音響環境に合わせて以下を手動実行してください。

1. **Exp1 / Exp2 実機キャリブレーション**
   ```bash
   PYTHONPATH=. .venv/bin/python -m src.experiments.run_exp1_exp2_calibration
   ```
   - 実行前にピアノ付近に人・障害物がないこと、ダンパーが正常動作することを確認する。
   - **Exp1**: C2〜C6 の複数ベロシティを発音し、AKG C519ML が実音の立ち上がりを検出して理論 VDL 曲線（`base_min_ms`, `amplitude_ms`, `decay_rate`, `bass_mass_slope`）を更新します。
   - **Exp2**: CC#64 の踏み込み深度を段階的に変化させ、C3〜G4 帯域の残響時間（`rt60_s`）と濁り係数（`acoustic_roughness`）を測定し、推奨ハーフペダル上限（標準 CC#58 前後）を SQLite（`data/telemetry/rd_studio.sqlite`）に記録します。
2. **UI グラフでの目視検証**
   - **「🧪 VDL校正＆ペダル実験」** タブ（`#vtab-experiments`）を開き、以下を確認します：
     - **Exp1 VDL 実測点 vs 理論フィット曲線**: 青点（実測）が金色曲線（理論フィット）付近に分布し、極端な外れ値がないこと。必要に応じて画面下部のパラメータ入力欄から手動微調整可能。
     - **Exp2 ハーフペダル RT60 ＆ 濁り曲線**: CC#58 付近の推奨ハーフペダル帯域で濁りが抑えられていること。

## 4. かぶり分離・チェロ対話・長時間運転チェック（Exp3〜Exp5 参考）

1. **同一室内でチェロ（または参考楽器）を弾いた際の分離確認**
   - **「🎻 チェロ共演＆IMSLP深層解析」** タブで UR22mkII / C519ML 入力を確認し、`🎤` バッジと音高検出表示が実音に追従することを確認する。
   - 「チェロへ呼応するフレーズ」ボタンを押した直後、**「🤝 人間演奏 vs AIピアニスト応答 比較グラフ」** に人間側と AI 側の音高輪郭が正しく表示されることを確認する。
2. **長時間安全監視**
   - 5〜10分間の連続演奏時は **「🛡️ 安全監視＆実機プロファイル」** タブを開き、以下のグラフを監視する：
     - 同時保持音数が設定上限（例: `20`）を下回り続けていること。
     - 打鍵速度が上限（例: `28 音/秒`）を超過しないこと。
     - **「⚡ 高速化・ジッター＆通信診断」** タブで Condition 起床ジッター（平均 `< 1ms` / p95 `< 2ms` 目安）と未処理例外ゼロを確認する。
3. **終了手順**
   - 演奏終了時は必ず **「🛑 全音緊急停止 (PANIC)」** を一度クリックし、全鍵・ペダルが解放された状態でサーバーを停止（`Ctrl+C`）する。
