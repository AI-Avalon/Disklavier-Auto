# DISKLAVIER STUDIO ユーザーガイド（実機・デモ完全対応）

DISKLAVIER STUDIO は、人間（チェロまたはピアノ）の演奏に呼応して 6並列パイプラインで作曲・和声検証・ペダル制御を行うリアルタイム演奏システムです。また、ローカル LLM / NotaGen による「一からのリアルタイム生成」デモと、厳選 100 作品のタイムマシン・アーカイブも統合しています。

---

## 1. 3分クイックスタート（デモで動作確認）

PC とスピーカー（またはヘッドホン）だけで、すべての対話作曲機能と音声出力を試せます。

1. リポジトリ直下の `run_demo_showcase.bat` をダブルクリックします。
2. ローカルサーバー起動後、`active_stage_url.txt` に書き出された URL（通常 `http://127.0.0.1:8000/studio?demo=1`）がブラウザで開きます。
3. 画面上部の4つのタブでモードを切り替えます：
   - **`[1] チェロ対話`**: 「仮想チェロでデモ開始」またはテストフレーズ送信ボタンでチェロ対話を開始します。
   - **`[2] ピアノ対話`**: 画面上の鍵盤クリック、または PC キーボード `A W S E D F T G Y H U J K` で弾くと即時に和声応答が返ります。
   - **`[3] LLM/NotaGen 作曲ライブ`**: 日本語イメージと数音の種モチーフから、ABC 記譜が1小節ずつストリーミング生成され即座に発音されます。
   - **`[4] 楽曲ライブラリ`**: 厳選 100 曲とスタジオ収録 MP3（10 曲）を 4層ミキサー（SOLO/MUTE）と大譜表タイムマシンで聴き分けられます。

## 2. 本番実機セットアップ（Yamaha Disklavier + チェロ用 UR22 / AKG C519ML）

### 必須確認事項：Disklavier 本体設定
- **Delay In = OFF（極めて重要）**:
  - Disklavier ENSPIRE / Pro などの設定メニューにある「Delay In（外部MIDI入力の再生遅延補正 / 約500msバッファ）」が ON になっていると、人間の打鍵やチェロ呼吸に対して半秒以上遅れて発音してしまいます。
  - **必ず `Delay In = OFF`** に設定してください（MIDI ケーブル / USB-MIDI 経由のリアルタイム即応性を確保します）。

### 配線手順
1. **Yamaha Disklavier 接続**:
   - PC と Disklavier を USB-MIDI（または MIDI-IN/OUT インターフェース）で接続します。
   - `start_stage.bat`（実機舞台モード）または `run_demo_showcase.bat` を起動し、ヘッダー右側の接続スイッチを **`接続: 本番実機 (Disklavier/UR22)`** に切り替えます。
2. **チェロ対話（Mode 1 / UR22 + AKG C519ML）**:
   - AKG C519ML コンデンサーマイクをチェロ（駒付近/f字孔外縁）へ装着し、Steinberg UR22 の Input 1（48V ファンタム電源 ON）へ接続します。
   - `[1] チェロ対話` タブを開き、演奏開始前に **`2chエコー較正`** ボタンを押します。ピアノの基準音に対するマイク回り込みを 2ch NLMS 適応フィルタが学習し、ピアノ音をキャンセルして純粋なチェロ音程（F0）とビブラートだけを抽出します。
3. **物理ペダル配置の確認（画面表示と実機足元の一致）**:
   - **左ペダル**: `UNA CORDA (CC#67)` — 柔音・倍音抑制（第4幕の静かな終止や内省表現で使用）
   - **右ペダル**: `DAMPER (CC#64)` — 残響保持・和声変更時の踏替（ハーフペダル帯域 `28%〜63%` の強調表示あり）

## 3. 各モードの詳しい操作

### `[1] チェロ対話`
- **4幕構成インジケーター**: 第1幕（静かな呈示）→ 第2幕（展開と対話）→ 第3幕（頂点の高揚・朱色強調）→ 第4幕（余韻と終止）の流れを一目で確認できます。
- **演奏への指示入力欄**: 「中音域で半歩引いて、左ペダルで支えて」などの日本語指示を送ると、LLM意図ワーカー（Worker 3）が直ちに作曲方針へ反映します。
- **4候補比較カード & 大譜表**: 案A〜D をクリックすると、採用候補だけでなく**ボツになった候補の楽譜と棄却理由**も大譜表上に切り替えて試聴・検証できます。

### `[2] ピアノ対話`
- **色分けガイド**: 鍵盤上の **水色 (`#A8C8E8`)** が人間の打鍵、**金色 (`#E5C88F`)** が AI 先読み・予定音、**朱色 (`#C83E2B`)** が L5 出力確定打鍵です。
- **左ペダル合図 (`CC#67`)**: 「左ペダル合図」ボタンまたは実機ピアノの左ペダル踏み込みを検知すると、即座に投機的バッファを確定してターンを交代します。
- **自己打鍵分離**: AI 自身が Disklavier で鳴らした鍵盤を人間入力と誤認しないよう、タイムスタンプ窓と MIDI ピッチ照合で厳密に除外します。

### `[3] LLM/NotaGen 作曲ライブ`
- **RTX 3070 (8GB VRAM) 動的切り替え**: Ollama と NotaGen-Small が同時に 8GB を溢れて OOM クラッシュしないよう、`vram_manager.py` が切替時に未使用モデルの VRAM を自動解放（Ollama `keep_alive=0` + `torch.cuda.empty_cache()`）します。
- **ライブ生成**: 楽曲コンセプト・調性・開始モチーフ・小節数を選び、「一からライブ生成＆即時演奏」を押すと ABC 記譜トークンが左コンソールへ流れ、和声・声部連結ガードを通過した小節から右の大譜表へ描画されて即座に鳴り響きます。
- **作品書き出し**: 「作品を保存」で `WAV` / `MP3` / `MIDI` / `MusicXML` と `Obsidian` セッション記録を一括保存します。

### `[4] 楽曲ライブラリ`
- **検索・絞り込み**: 全 100 曲・高音質 MP3（10曲）・チェロ共演・ピアノ共演・様式フィルターを組み合わせて即座に選曲できます。
- **4層パート別ミキサー**: 人間主役・AI右手主旋律・AI右手内声・AI左手バスの各層を個別に `SOLO` / `MUTE` して対位法を学習できます。
- **現在位置から先を生成**: ライブラリ再生中の和音・位置を引き継ぎ、そのまま `[3] LLM/NotaGen 作曲ライブ` へ種モチーフを渡して続きを作曲させられます。

## 4. 緊急時・舞台投影・ショートカット

- **PANIC 全消音 (`Esc` キー / 右上ボタン)**: すべての MIDI ノートオフ・ペダル解除（CC#64=0, CC#67=0）・ローカル再生を 10ms 以内に停止します。
- **舞台投影クリーン表示 (`F10` キー)**: 上部の操作タブ・診断 HUD・ガイド帯を隠し、大譜表と作曲メモ・ペダル情報だけをステージ背景向けに大きく表示します（再度 `F10` または右上の「通常表示に戻る」で復帰）。
- **舞台専用投影画面 (`/stage`)**: プロジェクター専用レイアウトとして `/stage` を別ウィンドウで全画面表示することもできます。
