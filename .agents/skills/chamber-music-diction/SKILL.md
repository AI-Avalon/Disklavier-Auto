# Chamber Music Diction Skill (室内楽リハーサル語彙規約)

## 1. 絶対禁止事項（AIポエム・クリシェ・音楽理論矛盾の排除）
- **音楽的矛盾の禁止**:
  - 例（NG）: `長三度の空虚五度`, `短三度の空虚五度`, `三度を含む空虚五度`（空虚五度は第3音を省いた五度であるため矛盾）
  - 例（NG）: `単音の和音`, `無音の強奏`, `スタッカートのレガート`, `ペダル無しの深い残響`
- **AIポエム・小説風の気取った表現・クリシェの禁止**:
  - 禁止語句: `緊張を高める`, `余白を残して`, `解決を待つ`, `共鳴`, `呼応し`, `寄り添う`, `紡ぐ`, `織りなす`, `悲痛`, `歓喜`, `魂`, `アルゴリズム`, `回路`, `静寂を切り裂く`, `〜だろう`, `〜かもしれない`, `素晴らしい`, `感動的`, `美しい演奏`, `ありがとう`, `心の震え`, `AIとして`
- **記号・装飾の禁止**:
  - 感嘆符（`!`、`！`）、絵文字、顔文字、`♪` `★` `✨` などの装飾記号を含めない。

## 2. 事実ベースの3要素メモ規約（40〜75文字）
`monologue_ja` は必ず **L1知覚結果** と **L3候補生成・採点結果（採用案とボツ案の具体的音高・音域・減点理由）** に基づき、以下の3要素を含む飾り気のない実用メモ（**40〜75文字**）とする：
1. **【状況】** 実際に検出された音と奏法（例：`チェロのD3→F3レガートを検出。`）
2. **【迷い・却下理由】** ボツにした案の具体的欠点（例：`中音域和音の案DはD3倍音と濁るためボツにし、`）
3. **【決定】** 最終的に選んだ具体的な手（例：`左手は抜き高音A4-E5の反行案Aを浅いペダルで置く。`）

## 3. 模範出力例
- `チェロのD3→Eb3半音上行を検出。中音域和音の案DはD3倍音と濁るためボツにし、高音A4-E5の反行案Aをペダル無しで置く。`
- `チェロA3→C4のスタッカートを捕捉。同音反復の案Bは停滞するため棄却し、バスD2-A2の対位法反行案Aをドライで返す。`
- `ピアノE4→D4の終止を検出。中域密集の案Dは3度重複で濁るため捨て、上声部B4-E5の案Cをハーフペダルで接続する。`
