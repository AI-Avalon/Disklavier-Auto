# Stage Editorial UI Skill (High-Craft Dark Editorial Aesthetic)

## 1. 絶対禁止事項（Anti-AI Slop）
- **サイバーパンク風ネオンカラーの禁止**: シアン（`#00FFFF`）、マゼンタ発光、レーザー調のグリッド、ネオンテキストシャドウを一切使用しない。
- **過剰なグラデーション・装飾の禁止**: 虹色・多色グラデーション、ガラスモーフィズムの過剰使用、背景を埋め尽くす光彩を禁止する。
- **SF映画風演出の禁止**: 意味のない回転リング、レーダースイープ、装飾だけの疑似波形アニメーション、点滅する `AI THINKING...` / `NEURAL PROCESSING...` 等の安っぽい演出を全面禁止する。
- **絵文字・過剰記号の禁止**: 舞台投影面に絵文字（🎹🎻✨🔥等）や感嘆符を露出させない。

## 2. 舞台エディトリアル美学（High-Craft Dark UI）
- **背景**: 舞台照明と客席の視認性を妨げない深いマットブラック `#060608` を基調とし、境界線は極細の低明度ルール（`#1E1D1A` / `#2A2824`）で区切る。
- **厳選3色系（Strict 3-Color Palette）**:
  1. **羊皮紙オフホワイト (`#EAE6DF`)**: 採用された音符、五線譜、確定済みの分析テキスト、現在有効な楽曲データ。
  2. **ミュートグレー (`#5A5852`)**: 棄却されたボツ案の楽譜、棄却理由刻印、過去の控えめな履歴。
  3. **ヴァーミリオン (`#C83E2B`)**: 現在物理発音中の打鍵、和声衝突警告、ターンの重要焦点のみに限定使用する。
- **タイポグラフィ**:
  - **明朝体 / セリフ体 (`Noto Serif JP`, `Cormorant Garamond`, `Yu Mincho`, serif)**: ヘンレ版（Henle Urtext）やベーレンライター版（Bärenreiter）、IRCAMの解析画面を想起させる楽譜タイトル、強弱記号、速度標語、日本語アナリーゼ独白。
  - **等幅フォント (`JetBrains Mono`, `Cascadia Mono`, monospace)**: ミリ秒計測（ms）、F0周波数（Hz）、MIDIノート番号、ベロシティ、ポリフォニー数などの精密数値のみに使用する。

## 3. 舞台4ゾーンレイアウト（F10で操作バー完全格納）
- **Zone A（左上：知覚と呼吸）**: チェロF0ピッチ軌跡・ビブラート・アーティキュレーション（またはピアノ入力・ペダル開度・エコー抑圧台帳）、および人間フレーズの終止（呼吸）ゲージ。
- **Zone B（右上：実演家の思考トレース）**: 簡潔な音楽的思考メモ（`monologue_ja`）、対話スタンス、調性・旋法、和声進行、音域制約、ペダル方針。
- **Zone C（中央メイン：公開推敲・楽譜アリーナ）**: 3〜4個の候補フレーズの五線譜を並置表示し、ボツ案に棄却理由タグを刻印して `#5A5852` へ沈め、採用1案のみを `#EAE6DF` 〜 `#C83E2B` で実機打鍵と同期発光させる。
- **Zone D（下部：公演モチーフ記憶グラフ）**: 開演時はノード0から始まり、人間のモチーフ記録ノードとAIによる引用・変奏ノードが時間軸上で結ばれる系統グラフ。
